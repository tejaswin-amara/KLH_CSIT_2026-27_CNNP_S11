## 1. Objective

Capture live TCP, UDP, and ICMP packets on an active WSL2 network interface using `tshark`, isolate protocol streams with display filters, and verify Layer 2–4 encapsulation structure and header overhead.

---

## 2. Execution Workflow

```bash
# 1. Install capture and network utilities
sudo apt update && sudo apt install -y wireshark tshark curl dnsutils iputils-ping

# 2. Discover active WSL2 network interfaces
ip -br link
sudo tshark -D

# 3. Capture traffic while generating HTTPS (TCP), DNS (UDP), and Ping (ICMP) packets
IFACE="$(ip -4 route get 1.1.1.1 2>/dev/null | awk '{for (i=1; i<=NF; i++) if ($i == "dev") {print $(i+1); exit}}')"
test -n "$IFACE" || { echo "Set IFACE manually from 'tshark -D'"; exit 1; }
sudo tshark -i "$IFACE" -a duration:20 -w ~/sender_capture.pcapng &
curl -sI https://www.google.com
nslookup google.com
ping -c 4 8.8.8.8

# 4. Filter captured frames by protocol and payload presence
tshark -r ~/sender_capture.pcapng -Y "tcp" | head -n 15
tshark -r ~/sender_capture.pcapng -Y "udp" | head -n 15
tshark -r ~/sender_capture.pcapng -Y "icmp"
tshark -r ~/sender_capture.pcapng -Y "tcp.len > 0" | head -n 15
```

## 3. Observations & Header Reference

### Terminal & Filter Findings

| Check / Filter | Observed Output |
| --- | --- |
| **Active Interface (`ip -br link`)** | `eth3` (`d0:37:45:2e:63:10`) confirmed `UP`; `eth0`–`eth2` were `DOWN` |
| **TCP Stream (`tcp` / `tcp.len > 0`)** | 3-way handshake (`SYN`, `SYN-ACK`, `ACK`) + TLSv1.2/TLSv1.3 traffic to port `443` |
| **UDP Stream (`udp`)** | DNS query and response frames generated by `nslookup google.com` |
| **ICMP Stream (`icmp`)** | 4 Echo requests to `8.8.8.8` (outbound `TTL = 64`) and Echo replies (`TTL = 113`) |

### Standard Protocol Header Reference

| OSI Layer | Protocol | Standard Header Size |
| --- | --- | --- |
| **Layer 2 (Data Link)** | Ethernet II | `14 bytes` |
| **Layer 3 (Network)** | IPv4 (without options) | `20 bytes` |
| **Layer 4 (Transport)** | TCP / UDP | `20–32 bytes` (TCP) · `8 bytes` (UDP) |
